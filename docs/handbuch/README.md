# Handbuch

Dieses Handbuch erklärt Bellegio in einfacher Sprache — für Kita-Leitung, Verwaltung und Träger-Administration. Du brauchst kein Vorwissen. Jedes Kapitel beginnt mit „Was willst du tun?“ und führt Schritt für Schritt dorthin.

**Wichtig vorab:** Bellegio ist eine **Planungshilfe**. Es rechnet nach den Landesgesetzen, ersetzt aber weder deinen Zuwendungsbescheid noch die amtliche Meldung noch eine Rechts- oder Steuerberatung.
